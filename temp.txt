There are changes I want to make to the codebase:

1. Calibration robustness:
    More poses are going to be going to be added to the calibration file, recording examples of max left, right, up and down positions.
    These positions are going to be mapped to when the hand is at the max left, right up, and down positions in the camera frame, which thus maps to max x, y, and z in the robot workspace
    Add a learning element where the robot can learn how to reach mappped positions from handtracking based on the max/min motor values as well as some of the prerecorded full max/min positions

2. Max speed percent value
    Add a value to values.py that is able to controll the overall speed factors of the robot (acceleration, torque, speed) and is able to manipulate all the other speed related variables my a constant percentage value
    This does NOT affect the gripper motor, which should always operate at 100% speed

3. Wrist orientation
    Wrist orientation should dictage the roll, pitch, and yaw of the end effector, with the wrist orientation being treated as a sort of virtual spherical joint
